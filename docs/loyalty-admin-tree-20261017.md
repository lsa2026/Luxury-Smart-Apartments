# شجرة أعضاء برنامج الولاء — ١٧ أكتوبر ٢٠٢٦

## النطاق

توسيع صفحة الشجرة الإدارية القائمة، مع بطاقة واضحة داخل إدارة الولاء.
لا تغيير في الجداول أو العضويات أو العلاقات أو النقاط أو شروط البرنامج أو صلاحياته.

## مصدر الحقيقة

تُقرأ العضويات وعلاقات الدعوة الحالية، بما فيها تصحيحات الربط الموثقة.
لا تُستنتج الدعوة من الإهداء، ولا يُستخدم الرقم الشجري التاريخي المحفوظ في
حركة حسابية لاستبدال العلاقة الحالية. لذلك يظهر العضو الذي لم يكتسب نقاطًا بعد.

## تجربة الإدارة

- بطاقات أسماء وأرقام عضوية وأرقام شجرية وحالة العضوية وعدد المدعوين المباشرين.
- وصلات مرسومة متعددة المستويات، وفتح وطي الفروع، والتركيز على عضو ومسار داعيه.
- بحث بالاسم أو رقمي العضوية والشجرة أو الجوال الموثق؛ لا يعتمد رقم تواصل غير موثق.
- نتائج الاسم المتشابه تتطلب اختيار العضو، ولا يُختار شخص عشوائي.
- رابط سجل النقاط لكل عضو، دون إدراج البريد أو الجوال في بطاقات الرسم.
- عرض رأسي للجوال، ورسم أفقي قابل للتمرير على الحاسوب؛ لا مكتبة رسوم خارجية.
- تحميل عشرين عضوًا في الدفعة، مع المزيد، وحد القراءة الحالي عشرة آلاف علاقة.
  عند تجاوز الحد تظهر رسالة صريحة بدل شجرة جزئية توصف بأنها كاملة.
- تتحدث البيانات عند إعادة تحميل الصفحة؛ لا ادعاء تحديث لحظي أو قناة أحداث جديدة.

## الحماية والفحص

صفحة الرسم وأجزاء تحميل الفروع تمر جميعها بصلاحية مالك التشغيل القائمة،
وبالعربية، ومن دون تخزين مؤقت. الطلبات للقراءة فقط. لا يقبل المتصفح صفحة
تسجيل دخول أو استجابة غير معرّفة على أنها فرع، ولا يرسل طلبات لمصدر آخر.
يبقى التنقل بين الفروع متاحًا دون تشغيل التحسين التفاعلي.

اختبارات افتراضية تغطي الأعضاء بلا رصيد، والربط المصحح، والمستويات المتعددة،
والجوال الموثق، وتشابه الأسماء، والعضوية غير النشطة، والصفحات، والصلاحيات،
وعدم تعديل السجل، وإخفاء بيانات التواصل، وهروب النصوص، والحدود والفراغ.
اختبارات المتصفح البرمجية تشمل الطي والفتح، ومنع تكرار التحميل، وتعطل الاتصال،
والاستجابات غير المتوقعة، والصفحات الإضافية. لا إرسال أو دفع أو تحويل حقيقي.

حالة النشر وقبول المالك ودليلها تحفظ في مهمة المتابعة ومفكرة المشروع؛
وجود هذا الملف لا يثبت النشر أو القبول بمفرده.
