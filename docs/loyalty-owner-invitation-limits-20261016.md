# الاستثناء الشخصي لحدود الدعوات

طلب المالك في ١٦ أكتوبر ٢٠٢٦ إتاحة الدعوات له دون حدود عددية بعد تعذر إعادة دعوة رقم سبق أن استلم الدعوة في اليوم نفسه.

- النطاق: عضوية المالك القائمة `LSA-M000001` فقط، وفق سجل المحادثة وتجربته السابقة.
- المطابقة برقم العضوية المحفوظ على الخادم، لا اسم العرض أو حقل يكتبه الضيف أو جوال المستلم.
- لا تغيير لرقم العضوية أو هوية صاحبها أو صلاحياتها، ولا منح للاستثناء لمديري الموقع تلقائيًا.
- تُتجاوز حدود العدد اليومية الثلاثة للعضوية المحددة فقط؛ لا تستهلك طلباتها حصة الضيوف الآخرين.
- تبقى حدود الأعضاء الآخرين كما هي، وتبقى حدود بحث الأرقام وحماية رموز الدخول دون تغيير.
- تبقى شروط العضوية النشطة والتحقق والموافقة وأهلية رابط الدعوة ونطاق التجربة الخاصة مفعلة.
- إعادة تأكيد الطلب نفسه لا ترسل رسالة ثانية؛ لإعادة الدعوة يبدأ المالك طلب دعوة جديدًا.
- النتيجة غير المؤكدة عند المزود لا تعاد تلقائيًا، ولا يعاد تشغيل أي طلب قديم بمجرد النشر.
- يسجل الطلب سياسة الحد المستخدمة في بياناته الموجودة، دون جدول أو ترحيل أو إعداد اتصال جديد.
- هذا استثناء لحدود الموقع فقط، ولا يغيّر حدود مزود الخدمة أو حالة اتصال رقم الأعمال أو يضمن التسليم.
- الاختبارات محلية ببيانات افتراضية وبدون إرسال رسائل فعلية. النشر والتحقق يوثقان في سجل المتابعة القائم.
