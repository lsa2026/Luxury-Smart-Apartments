التحصيل

مسار رابط الدفع

HyperPay بانتظار تأكيد واجهة API لروابط hypbill.com لن نفترض أن API الـCheckout الحالية تنشئ روابط مستضافة قبل رد فريق HyperPay.
بديل تشغيلي طلب رابط يدوي للمحاسبة يُرسل النظام بيانات الحجز الضرورية فقط، ثم يُسجل الرابط قبل إرساله للضيف.

لن يُفعّل الإرسال عبر WhatsApp أو أي إجراء مالي في هذه المرحلة.
